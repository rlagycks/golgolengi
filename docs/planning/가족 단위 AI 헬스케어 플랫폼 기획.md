# 가족 단위 AI 헬스케어 플랫폼 기획 (Family Health OS)

## 🚀 가족 단위 AI 헬스케어 플랫폼 기획 (Family Health OS)

---

## 1) 서비스 정의

### 💡 한 줄 정의

**“개인의 건강이 아닌, 가족의 건강을 운영하는 AI 기반 예방 헬스케어 플랫폼”**

---

## 2) 문제 정의 (Problem)

### 2.1 건강 데이터의 파편화

- 개인별 데이터가 분산됨 (웨어러블 / 병원 / 앱)
- **가족 단위로 통합 관리가 불가능**

### 2.2 질병은 가족 단위로 발생

- 유전 + 환경 + 생활습관을 가족이 공유
- 하지만 대부분의 관리 시스템은 **개인 중심**

### 2.3 행동 변화 실패

- 개인 혼자서는 습관을 유지하기 어려움
- 건강 앱 전반적으로 **리텐션이 낮음**

### 2.4 예방 중심 관리 부재

- 시장은 치료 중심(사후 대응)에 집중
- **사전 개입(예방)의 시스템화가 부족**

### 2.5 보험과 건강관리의 단절

- 보험은 사후 보장 중심
- 건강관리는 별도 앱/서비스로 분리되어 **연계가 약함**

---

## 3) 핵심 솔루션

### 🔷 Family Health Operating System (FHOS)

가족을 하나의 “건강 운영 단위”로 보고, 다음을 통합 제공:

- 가족 단위 데이터 통합
- AI 기반 질병 위험 예측
- 가족 공동 행동 변화 유도
- 보험/금융 연계(핵심 BM)

---

## 4) 기능 구조 (Feature Architecture)

## 4.1 가족 건강 그래프 (Family Health Graph)

### 📌 기능 설명

- 가족 구성원을 하나의 네트워크로 연결
- 질병 이력 + 생활 패턴을 가족 단위로 통합

### 🔧 세부 기능

- 가족 구성원 초대 / 연결
- 관계 설정 (부모, 자녀 등)
- 가족 질병 이력 입력 (고혈압, 당뇨 등)
- 생활 습관 데이터 통합 (수면, 식단, 운동)

### 📊 출력 데이터(화면/리포트)

- 가족 건강 구조 시각화
- 유전/환경 기반 위험 연결(요인 링크)

---

## 4.2 AI 질병 예측 엔진

### 📌 기능 설명

- 개인 데이터 + 가족 데이터를 결합해 **질병 위험 예측**

### 🔧 세부 기능

- 위험 질환 예측
    - 당뇨
    - 심혈관 질환
    - 비만
    - 고혈압
- 위험 점수 (0~100)
- 발병 가능성 타임라인

### 📊 출력 데이터(예시)

- “3년 내 당뇨 위험 65%”
- 가족 영향 요인 분석(가족력/생활습관 기여도)

### ⚙️ 구현 단계(현실적인 로드)

- 초기: 룰 기반 (BMI, 가족력, 나이 등)
- 이후: 머신러닝 모델 적용

---

## 4.3 가족 행동 미션 시스템 (Core Feature)

### 📌 기능 설명

👉 개인이 아닌 **가족 단위 행동 변화 유도**에 집중

### 🔧 세부 기능

- 가족 공동 목표 설정
    - 하루 8,000보
    - 주 3회 운동
    - 저당 식단
- 미션 진행률 트래킹
- 가족 랭킹 / 점수 시스템
- 알림 및 리마인드

### 🎮 게임화 요소

- 배지 시스템
- 연속 달성(Streak)
- 가족 간 경쟁 구조

---

## 4.4 건강 리스크 대시보드

### 📌 기능 설명

- 가족 전체 건강 상태를 한눈에 보여주는 UI

### 🔧 세부 기능

- 가족 평균 건강 점수
- 개인별 위험도 비교
- 주요 리스크 TOP3 표시
- 변화 추이 그래프

---

## 4.5 데이터 통합 시스템

### 📌 기능 설명

- 다양한 건강 데이터 소스를 통합 수집/정규화

### 🔗 연동 대상

- 웨어러블 기기
- 건강 앱
- 병원 데이터 (장기 목표)

### 🔧 세부 기능

- 자동 데이터 수집

- 이상치 탐지

## 4.6 보험 연동 기능 (핵심 BM)

### 🔧 세부 기능

# 🚀 UX & Growth 확장 PRD

## 📱 10. 온보딩 질문 UX 설계

### 🎯 목표

- 3분 내 완료
- 가족 단위 핵심 데이터 확보
- 이탈 최소화

### 🧩 온보딩 구조 (Step Flow)

#### STEP 1. 가족 생성

- 가족 이름 입력 (ex. 김철수 가족)
- 가족 구성원 추가 (최소 2명)

#### STEP 2. 가족 관계 설정

- 관계 선택
    - 본인
    - 부모
    - 배우자
    - 자녀

**UX 포인트**

- 드래그 기반 관계 연결 (그래프 형태)

#### STEP 3. 건강 기본 정보

**질문 예시**

- 키 / 몸무게
- 현재 질환 여부
- 복용 중인 약 여부
- 가족력 선택 (복수 선택)
    - 당뇨
    - 고혈압
    - 심혈관질환

**UX 방식**

- 카드형 선택 UI
- 최대 5초 내 선택 가능

#### STEP 4. 가족 공동 식습관

**질문**

- 주 7일 중 함께 식사하는 날은?
- 외식/배달 빈도는?
- 야식 빈도는?

**UX**

- 슬라이더 + 이모지 기반

#### STEP 5. 생활 리듬

**질문**

- 평균 취침 시간
- 기상 시간
- 주말/평일 차이

**UX**

- 타임 휠 (Time picker)

#### STEP 6. 돌봄 관계

**질문**

- 가족 건강을 주로 챙기는 사람은?
- 관리가 필요한 사람이 있는가?

**UX**

- “역할 배지” 선택

#### STEP 7. 초기 목표 설정

**질문**

- 가장 관리하고 싶은 것 선택
    - 체중
    - 혈당
    - 수면
    - 운동

**UX**

- 1개 선택 (선택 피로 감소)

#### STEP 8. 완료 + 즉시 피드백

**보여줄 것**

- 가족 건강 점수 (초기)
- 주요 리스크 2개
- 추천 첫 미션

### 🎯 핵심 UX 원칙

- 입력 < 선택
- 텍스트 < 시각 UI
- 개인 질문 → 가족 질문 순서

## 📊 11. 리스크 점수 계산 로직

### 🎯 목표

- 설명 가능한 점수
- 빠른 계산
- MVP에서 구현 가능

### 🧠 전체 구조

**Risk Score = (유전 + 생활습관 + 행동 + 환경 + 의료) 가중합**

### 📐 구성 요소

#### 1) 유전 (Genetic Risk) — 30%

- 가족력 존재 여부
- 조기 발병 여부

#### 2) 생활습관 (Lifestyle) — 25%

- 식습관 점수
- 활동량
- 음주/흡연

#### 3) 행동 (Behavior) — 20%

- 챌린지 참여율
- 복약 순응도

#### 4) 환경 (Environment) — 15%

- 수면 환경
- 생활 리듬

#### 5) 의료 (Clinical) — 10%

- BMI
- 혈압
- 기존 질환

### 📊 계산 예시

- 유전: 70
- 생활습관: 50
- 행동: 60
- 환경: 40
- 의료: 30

👉 최종 점수 = 55

### 🔥 리스크 분류

- 0~30: 낮음
- 31~60: 주의
- 61~80: 위험
- 81~100: 고위험

### 🧩 MVP 구현 방식

- 룰 기반 scoring
- if-else 구조

### 🚀 확장

- ML 기반 예측
- 개인화 가중치 조정

## 🔁 12. 첫 2주 리텐션 설계 (핵심)

### 🎯 목표

- D1 retention ≥ 50%
- D7 retention ≥ 30%
- 가족 참여 유지

### 📅 Day 0 (가입 당일)

**경험**

- 즉시 결과 제공
- 첫 미션 자동 생성

**액션**

- 가족 초대 유도

### 📅 Day 1~3

**핵심 전략**

- “작은 성공 경험”

**기능**

- 초간단 미션
    - 물 5잔 마시기
    - 5,000보 걷기

**UX**

- 완료 시 즉시 보상

### 📅 Day 4~7

**핵심 전략**

- “가족 참여 유도”

**기능**

- 가족 랭킹
- 가족 알림

### 📅 Day 8~14

**핵심 전략**

- “패턴 인식 + 개인화”

**기능**

- 리포트 제공
    - “당신은 저녁에 이탈”
- 미션 자동 최적화

### 🎮 리텐션 핵심 장치

#### 1) 가족 압력 (Social Pressure)

- 가족 중 1명만 안 하면 표시

#### 2) 리더 시스템

- 가족 리더 지정

#### 3) 보상 구조

- streak
- 배지

#### 4) 감정 UX

- 칭찬 메시지
- 가족 응원

### 📊 KPI

- 미션 참여율
- 가족 초대율
- 주간 체크인율
