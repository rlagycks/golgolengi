## 4. 즉시 대응이 필요한 CRITICAL 리스크

### R-008: 미성년자 PIPA 위반 방지
- 코드 레벨: `is_minor = true`인 Member의 API 요청 시 `pipa_consent_by` 존재 여부 검증 미들웨어
- 테스트: AC-08 E2E 테스트 Sprint 4 필수 통과

### R-009: 의료기기법 위반 방지
- 모든 API 응답에 `disclaimer` 필드 포함
- 앱 모든 화면 하단 고정 면책 문구
- 리스크 점수 화면: "의료 진단이 아닌 건강 관리 참고 지표입니다" 문구 필수

### R-011: 건강 데이터 보안
- RDS 암호화 활성화 (at-rest)
- API 통신 HTTPS 강제 (HTTP redirect → HTTPS)
- HealthKit / Health Connect 데이터: 서버 저장 시 AES-256 적용

## 6. Exit Conditions (MVP 완료 기준)

- [ ] AC-01 ~ AC-10 전체 통과
- [ ] 온보딩 ~ 첫 챌린지 완료 E2E 플로우 크래시 없음
- [ ] 미성년자 PIPA 동의 플로우 정상 동작
- [ ] 가족 연결 + 챌린지 1개 완료 검증 완료
- [ ] 리스크 점수 계산 단위 테스트 통과
- [ ] LLM 가드레일 단위 테스트 통과
- [ ] CRITICAL 리스크 (R-008, R-009, R-011) 대응 완료 확인
