## 체크인 바텀 시트

챌린지 카드의 "체크인하기" 클릭 시 Bottom Sheet로 올라옴.

```
┌─────────────────────────────────────────┐
│                  ──                     │  드래그 핸들
│                                         │
│  체크인 방법 선택                       │  h3
│  우선순위: 웨어러블 > 수동 > 사진      │  caption, muted
│                                         │
│  ╔════════════════════════════════════╗ │
│  ║  📡 웨어러블 연동                  ║ │  card (outlined)
│  ║  Google Health / Apple Health     ║ │
│  ║  현재 8,234보 감지됨 ✓           ║ │  data 있을 때: success 컬러
│  ║  [웨어러블로 완료하기]             ║ │  Button Primary
│  ╚════════════════════════════════════╝ │
│                                         │
│  ─────────────── 또는 ───────────────  │  divider, muted
│                                         │
│  ╔════════════════════════════════════╗ │
│  ║  ✏️  수동 입력                      ║ │
│  ║  걸음 수를 직접 입력해요           ║ │
│  ║  ┌──────────────────────────────┐ ║ │
│  ║  │  7,500 보                    │ ║ │  input-field
│  ║  └──────────────────────────────┘ ║ │
│  ║  [수동으로 완료하기]              ║ │  Button Secondary
│  ╚════════════════════════════════════╝ │
│                                         │
│  ╔════════════════════════════════════╗ │
│  ║  📷 사진으로 인증                  ║ │
│  ║  운동 중 사진을 올리면 완료!      ║ │
│  ║  [사진 선택하기]                  ║ │  Button Ghost
│  ╚════════════════════════════════════╝ │
└─────────────────────────────────────────┘
  elevation-3, radius 상단: 24px
  bg: surface
```

**우선순위 로직:**
1. 웨어러블 데이터 있음 → 웨어러블 섹션 강조 (elevation-1 + border primary)
2. 웨어러블 없음 / 권한 거부 → 수동 입력이 첫 번째로 표시
3. 사진: 항상 세 번째 (업로드 자체가 완료 조건 — PRD AC-04)

## 체크인 완료 화면

```
┌─────────────────────────────────────────┐
│                                         │
│         [성공 애니메이션]               │  check-circle 48px, primary 컬러
│         체크인 완료!                    │  h2
│                                         │
│  ╔══════════════════════════════════╗  │  Card Elevated
│  ║  오늘 챌린지 완료                ║  │
│  ║  ─────────────────────────────  ║  │
│  ║  리스크 개선 예상: -2점          ║  │  primary + 화살표
│  ║  현재 스트리크: 🔥 8일 연속      ║  │  streak-chip
│  ╚══════════════════════════════════╝  │
│                                         │
│  가족들도 격려해요!                     │  h4
│  [김영희에게 응원 메시지]              │  가족 알림 트리거
│                                         │
│  [────────── 홈으로 ──────────]        │  Button Primary
│  다음 챌린지 보기                       │  Ghost 버튼
└─────────────────────────────────────────┘
```

**애니메이션:**
- 체크인 완료 시: 체크 원 scale 0.5 → 1.0 (300ms, spring)
- 점수 숫자 카운트업 애니메이션 (400ms)
- `prefers-reduced-motion`: 모든 애니메이션 즉시 표시

```
앱 내 알림 배너 (3초 자동 닫힘):
╭──────────────────────────────────────────╮

╰──────────────────────────────────────────╯
bg: risk-warning-bg, text: #92400E, 하단 고정
```

## 접근성

- 체크인 바텀 시트: 포커스 트랩 (모달 접근성)
- 웨어러블 연동 카드: 데이터 없을 때 `accessibilityLabel="웨어러블 데이터 없음, 수동 입력으로 진행하세요"`
- 완료 애니메이션: `accessibilityAnnouncement("챌린지 완료!")` (VoiceOver/TalkBack)
