# Screen Design: 리스크 대시보드 (Risk Dashboard)

> PRD AC-02 대응 | 룰 기반 리스크 점수 시각화

---

## 화면 목표

- 가족 전체 건강 상태를 한눈에 파악
- 5가지 리스크 요소의 기여도 시각화
- 시간에 따른 점수 변화 추이 제공
- LLM 미사용, 룰 기반 계산만 → 신뢰감 있는 설명 필요

## 리스크 구성 요소 시각화

```
리스크 구성 요소                          h4
─────────────────────────────────────────

유전 (30%)                               label-md
[██████████████████░░░░░░░░░░░] 70점    progress bar (risk-high 컬러)
고혈압 가족력, 당뇨 가족력               caption, muted

생활습관 (25%)                           label-md
[████████████░░░░░░░░░░░░░░░░░] 50점    progress bar (risk-warning 컬러)
외식 빈도 높음, 운동 부족               caption, muted

행동 (20%)                               label-md
[█████████████░░░░░░░░░░░░░░░░] 55점    progress bar (risk-warning 컬러)
챌린지 참여율 73%                        caption, muted

환경 (15%)                               label-md
[█████████████████░░░░░░░░░░░░] 65점    progress bar (risk-high 컬러)
평균 수면 5.5시간                        caption, muted

임상 (10%)                               label-md
[████████░░░░░░░░░░░░░░░░░░░░░] 32점    progress bar (risk-low 컬러)
BMI 정상, 기존 질환 없음                caption, muted
```

**progress bar 컬러 로직:**
- 각 요소 점수 → 리스크 등급 매핑 → 해당 risk 컬러 사용
- label 옆 소형 risk-badge 병용 (색상만으로 전달 금지)

## 설명 가능성 (Explainability) UI

룰 기반 점수의 신뢰감을 위해 "왜 이 점수인가"를 항상 설명.

```
╔═══════════════════════════════════════════╗
║  55점인 이유                              ║  h4
║  ─────────────────────────────────────── ║
║                                           ║
║  📈 높이는 요인                           ║  label-md, risk-high 컬러
║  · 가족력: 고혈압 (+18점)                ║  body-sm
║  · 수면 부족: 평균 5.5시간 (+12점)      ║
║                                           ║
║  📉 낮추는 요인                           ║  label-md, primary 컬러
║  · 챌린지 참여율 73% (-8점)              ║  body-sm
║  · 정상 BMI (-5점)                       ║
╚═══════════════════════════════════════════╝
```

## 리스크 등급 범례 (항상 표시)

```
╔══════════════════════════════════════════╗
║  리스크 등급 안내                        ║
║  ──────────────────────────────────────  ║
║  ● 낮음 (0–30)   건강한 상태            ║  risk-low 색상 점
║  ● 주의 (31–60)  관리가 필요해요        ║  risk-warning
║  ● 위험 (61–80)  적극적 관리 필요       ║  risk-high
║  ● 고위험 (81+)  의료 상담 권장         ║  risk-critical
╚══════════════════════════════════════════╝

caption 텍스트, 배경: surface-elevated
```
