## 데이터 공유 설정 (동의 기반 공유 — PRD 필수)

```
┌─────────────────────────────────────────┐
│  ← 데이터 공유 설정                     │
│                                         │
│  가족과 공유할 정보를 선택해요           │  h2
│  동의한 항목만 가족에게 공개됩니다       │  body-md, muted
│                                         │
│  ┌──────────────────────────────────┐  │
│  │  리스크 점수                [●]  │  │  토글 ON (primary)
│  │  점수와 등급이 공유됩니다    →   │  │  label-md + body-sm muted
│  └──────────────────────────────────┘  │
│  ┌──────────────────────────────────┐  │
│  │  챌린지 진행 현황           [●]  │  │
│  │  오늘 완료 여부가 공유됩니다→   │  │
│  └──────────────────────────────────┘  │
│  ┌──────────────────────────────────┐  │
│  │  건강 설문 상세 데이터      [○]  │  │  토글 OFF (border)
│  │  BMI, 질환 등 상세 데이터  →   │  │  비공개 상태
│  └──────────────────────────────────┘  │
│  ┌──────────────────────────────────┐  │
│  │  배지 및 스트리크           [●]  │  │
│  └──────────────────────────────────┘  │
│                                         │
│  [──────── 저장하기 ────────]          │  Button Primary
└─────────────────────────────────────────┘
```

**토글 스위치 스펙:**
- ON: primary 컬러 트랙 + 흰 원
- OFF: border 컬러 트랙 + 흰 원
- 크기: 44×24px (터치 타겟 충분)
