## 랭킹 화면

```
┌─────────────────────────────────────────┐
│  ← 가족 랭킹                            │
│                                         │
│  리스크 개선율 기준                     │  h4
│  점수가 낮을수록 건강해요               │  body-sm, muted
│                                         │
│  이번 달 기준                 [지난달]  │  라디오 탭
│                                         │
│  ╔═══════════════════════════════════╗  │  랭킹 리스트
│  ║  1위  👑  김철수               ║  │  bg: primary-container (본인)
│  ║       [self 40px]  28점   낮음  ║  │  risk-badge-low
│  ║       지난달 대비 ▼5점 개선     ║  │  body-sm, primary
│  ╠═══════════════════════════════════╣  │
│  ║  2위      김민준                ║  │  기본 surface bg
│  ║       [child 40px] 41점  주의   ║  │  risk-badge-warning
│  ║       지난달 대비 ▼2점 개선     ║  │
│  ╠═══════════════════════════════════╣  │
│  ║  3위      김영희                ║  │
│  ║       [parent 40px] 62점 위험   ║  │  risk-badge-high
│  ║       지난달 대비 ▲1점 상승     ║  │  risk-high 텍스트 (개선 못함)
│  ╠═══════════════════════════════════╣  │
│  ║  4위      김할머니              ║  │
│  ║       [avatar 40px] 78점 위험   ║  │
│  ║       지난달 대비 ▼3점 개선     ║  │
│  ╚═══════════════════════════════════╝  │
│                                         │
│  ╔═══════════════════════════════════╗  │  disclaimer
│  ║  ℹ 점수가 낮을수록 건강한      ║  │
│  ║    상태를 나타냅니다            ║  │
│  ╚═══════════════════════════════════╝  │
└─────────────────────────────────────────┘
```

**랭킹 로직:**
- 정렬 기준: 리스크 점수 낮은 순 (낮음 = 건강함)
- 동점 시: 챌린지 참여율 높은 순
- delta 표시: 이전 달 대비 점수 변화 (개선 → primary, 악화 → risk-high)
