# Screen Design: 온보딩 (Onboarding)

> PRD AC-01, AC-08 대응 | 목표: 3분 이내 완료, 이탈 최소화

---

## 화면 흐름

```
[소셜 로그인] → [STEP 1 가족 생성] → [STEP 2 관계 설정] →
[STEP 3 건강 기본 정보] → [STEP 4 식습관] → [STEP 5 생활 리듬] →
[STEP 6 돌봄 관계] → [STEP 7 목표 설정] → [STEP 8 완료 피드백]

미성년자 분기:
[소셜 로그인] → [미성년자 감지] → [PIPA 부모 동의] → STEP 1로
```

---

## 공통 온보딩 레이아웃

```
┌─────────────────────────────────────────┐
│  ← (뒤로)           STEP N/8            │  App Bar
│  ─────────────────────────────────────  │  Progress Stepper
│                                         │
│                                         │
│  화면 제목 (h2)                         │  spacing.10 top margin
│  설명 텍스트 (body-md, muted)           │
│                                         │
│                                         │
│  [핵심 입력 영역]                       │  flex-grow: 1
│                                         │
│                                         │
│  [──────── 다음 ────────]               │  Bottom CTA
│  ○ 건너뛰기 (해당 단계만)              │  spacing.12 bottom
└─────────────────────────────────────────┘
```

- App Bar: 뒤로 버튼 + 단계 표시 (N/8 텍스트)
- Progress Stepper: 8개 점. 완료 primary, 현재 primary-outline, 미진행 border
- Bottom: Button Primary "다음" 항상 하단 고정

### S2. 미성년자 PIPA 동의 (분기 화면)

PRD AC-08 필수 구현. 미성년자 계정 감지 시 이 화면으로 강제 이동.

```
┌─────────────────────────────────────────┐
│  자녀 계정 보호를 위한 동의             │  h2
│                                         │
│  만 14세 미만은 법정대리인(부모)의      │  body-md, muted
│  동의가 필요합니다.                     │
│                                         │
│  ╔══════════════════════════════════╗  │
│  ║ ☑  개인정보 수집·이용 (필수)    ║  │  체크박스 + 전문 보기 링크
│  ║ ☑  제3자 제공 동의 (필수)       ║  │
│  ║ □   마케팅 수신 (선택)           ║  │
│  ╚══════════════════════════════════╝  │
│                                         │
│  부모님 이메일:                         │  input-field
│  ┌────────────────────────────────┐    │
│  │  parent@example.com            │    │
│  └────────────────────────────────┘    │
│                                         │
│  [──────── 동의하고 계속하기 ────────] │  disabled until all required checked
└─────────────────────────────────────────┘
```

**로직:**
- 필수 체크 미완료 → Button Primary disabled (#A7D7CA)
- 부모 이메일 유효성 검사 통과 + 필수 체크 완료 → 버튼 활성화
- 완료 시: `pipa_consent_by` 서버 저장
