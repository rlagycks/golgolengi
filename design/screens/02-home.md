# Screen Design: 홈 (Home Dashboard)

> PRD AC-02, AC-06 대응 | 가족 리스크 점수 최우선 렌더링

---

## 화면 목표

- 앱을 열면 3초 이내에 가족 건강 상태 파악
- 오늘의 챌린지 진행 상황 한눈에 확인
- 가족 중 누가 체크인했는지 즉시 확인
- 스트리크·배지 달성 상태로 동기 부여

## 컴포넌트 상세

### 1. 히어로 리스크 카드

```
리스크 점수에 따른 동적 컬러:

점수  링 색상            뱃지              배경 그라디언트 (미세)
0-30  risk-low #22C55E   "낮음" 초록 뱃지  surface
31-60 risk-warning #F59E0B "주의" 노랑 뱃지 surface (미세 amber tint)
61-80 risk-high #F97316    "위험" 주황 뱃지 surface
81-100 risk-critical #EF4444 "고위험" 빨강  surface
```

**점수 링 스펙:**
- 크기: 120px diameter
- 링 두께: 12px
- 빈 부분: border #E2E8F0
- 채워진 부분: 리스크 컬러 (점수/100 비율)
- 내부: score-hero 폰트, 점수 숫자

**개인별 점수 미니 표시:**
- 아바타 (32px) + 점수 숫자 (label-md)
- 역할 컬러로 아바타 구분
- 가로 배열, 가족 수에 따라 압축

### 2. Streak + Progress 칩 영역

```
[🔥 7일 연속]  [오늘 3/4명 완료]

streak-chip: bg #FEF9C3, text streak #F59E0B
progress-chip: bg primary-container, text primary
```

### 3. 오늘의 챌린지 카드

**마감 임박 상태 (2시간 전):**
```
╔═══════════════════════════════════╗
║  걷기  ·  마감 01:47 남음  ⏰     ║  시간 텍스트 → risk-warning 컬러
║  가족 함께 하루 8,000보 걷기       ║  카드 상단 border-top: 2px risk-warning
║  ──────────────────────── 3/4     ║
║  [⚡ 지금 체크인하기]              ║  버튼 → Button Accent
╚═══════════════════════════════════╝
```

**완료 상태:**
```

║  가족 함께 하루 8,000보 걷기       ║  text: on-primary-container
║  ████████████████████████ 4/4     ║  progress bar 100% primary
║  완료됨                            ║  버튼 비활성
╚═══════════════════════════════════╝
```

## 상태 처리

| 상황 | UI 처리 |
|------|---------|
| 첫 로딩 (데이터 없음) | 스켈레톤 로딩 (shimmer animation) |
| 웨어러블 연동 끊김 | 카드 상단 info 배너 "웨어러블 연결 필요" |
| 챌린지 없음 | Empty State + "챌린지 만들기" CTA |
| 오프라인 | 이전 데이터 표시 + "오프라인 상태" 토스트 |
| 가족 전원 완료 | 전체 화면 파티클 애니메이션 (1회) |

---

## 렌더링 우선순위

1. 리스크 점수 카드 (최상단, 최우선 로딩)
2. 오늘의 챌린지 카드
3. 가족 현황 (LCP 이후 로딩 허용)
4. 배지 섹션 (lazy load)

## 접근성

- 리스크 점수 링: `accessibilityLabel="가족 리스크 점수 55점, 주의 등급"`
- 개인 점수 아바타: `accessibilityLabel="김영희, 62점, 위험 등급"`
- 체크인 버튼: `accessibilityLabel="챌린지 체크인하기"`
